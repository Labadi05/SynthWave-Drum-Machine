# 🥁 SynthWave Drum Machine

An interactive, keyboard-driven drum machine with a retro-futuristic neon aesthetic.


## 📋 Features
- 9 unique drum pads with high-quality samples
- Full keyboard support (Q, W, E, A, S, D, Z, X, C)
- Real-time visual feedback
- Glowing display showing current sound
- Responsive design for all devices
- Zero dependencies - pure HTML/CSS/JS

## 🚀 Quick Start
Clone and open `index.html` in your browser.

## 🎵 Sound Library
| Key | Sound |
|-----|-------|
| Q | Heater 1 |
| W | Heater 2 |
| E | Heater 3 |
| A | Heater 4 |
| S | Clap |
| D | Open-HH |
| Z | Kick-n-Hat |
| X | Kick |
| C | Closed-HH |

## 🛠️ Built With
- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- Web Audio API
